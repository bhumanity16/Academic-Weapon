About the Project

How ScholarSync Is Built

ScholarSync is a full-stack web app: a Python (Flask) backend running as a serverless function on Vercel, a large language model through the Groq API to write the plans, and Google sign-in with the Calendar API to save them.

The code does the math, not the AI

Language models often get weekdays and time arithmetic wrong. The server works out today's date, the day of the week, days until the exam and how much time fits before your stop time, then gives those facts to the AI.

Plans that fit a school day

Weekday study starts after 4 PM and stays around 2–3 hours, weekends get more, and the Daily Booster never schedules past the stop time you choose. If your tasks don't fit, it tells you what got cut.

Private by design

There's no database. Plans aren't saved on the server, your streak and XP live only in your own browser, and calendar sync adds a single event only after you confirm it.

Built to be safe in public

Every input is checked on the server, requests are rate-limited, Google sign-in uses PKCE and state checks, and the AI's output is sanitized before it's shown on the page.
